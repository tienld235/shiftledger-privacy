# ShiftLedger — Privacy Policy & Terms

đăng bằng GitHub Pages: https://tienld235.github.io/shiftledger-privacy/

Neo: `#en`, `#es` mở đúng thứ tiếng; `#en-terms`, `#es-terms` cuộn tới mục Điều khoản.

`index.html` sinh tự động từ `store/privacy-policy.md` của repo app bằng `node tools/makePrivacyPage.cjs` —
đừng sửa tay ở đây; sửa nguồn rồi dựng lại.
